# Trapiche Loja Virtual

Bom dia, tudo bem?
Sou T.i da trapiche pescados... Quero fazer um sistema para meus clientes de atacado e varejo.
Atualmente utilizamos o CIGAM que meus proprios vendedores digitam os pedidos de restaurante(atacado) e o emissor de cupom fiscal (varejo).
Meu intuito desse sistema é facilitar a vida do meu cliente, para ele ter seu cadastro, digitar o pedido, selecionando o produto e condição de pagamento e futuramente ter uma API que esse pedido caia no meu sistema para o pessoal aprovar e faturar.
Esse sistema precisa ser configurável apenas por mim, para eu poder colocar meus produtos condições de pagamento e etc.
